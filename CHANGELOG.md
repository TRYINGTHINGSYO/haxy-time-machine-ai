# Changelog

## v0.1.0 — 2026-10-15

Initial public release of the existing Git Intelligence implementation.

- Incremental ordinary Git indexing with bounded patches, rename information, merge-parent views and historical line citations.
- Terminal commit/search/timeline explorer and selectable evidence inspection.
- Deterministic SQLite FTS5 retrieval, local Ollama interpretation, CPU defaults and optional guarded partial GPU offload.
- Persistent caches, resource diagnostics and repeated uncached benchmark support.
- Optional Haxy event reconstruction and explicit public synchronization.
- PowerShell launcher, documentation, attribution and Windows test workflow.

Publication preparation replaces bundled historical user data with an original, explicitly fictional demo fixture. Runtime databases, local repository clones, raw inference samples and development logs are not distributed. New benchmark output is written to ignored data/benchmarks/. A calendar-dependent test now uses fixed date bounds. Existing behavioral tests remain, plus public-distribution checks.

Limits: interpretations are not proof of causality; indexing is bounded; binary/oversized/shallow gaps are explicit; Haxy merged-event conflict processing is unsupported. Windows is release-tested. The aggregate performance report is a previously recorded development measurement, not a new release benchmark.
